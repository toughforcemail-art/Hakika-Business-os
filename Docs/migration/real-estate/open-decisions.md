# Vertical slice decisions

- Planned unit count is planning data; actual totals come from active unit rows.
- Photo storage is deferred until the bucket ownership model is confirmed; only the additive photo contract is prepared.
- Unit/property archive uses `archived_at`; hard delete is revoked for the new slice.
- Hosted migration application is blocked pending verified Supabase connectivity to project `upvupkuokinwqwsfxyxy`.
